# Research

Security companies and researchers publish reports on attacks through agent skills, plugins, MCP servers and packages. The files below collect those reports and the attack techniques they describe. We plant the techniques into copies of real skills and test the scanner on the copies.

| File | Contents |
|---|---|
| [Sources](sources.md) | Links to the reports. The tables split them into attacks found in the wild, research demos, and attacks on packages and repositories. |
| [Attack techniques](attacks.md) | One row per technique that puts something into the files of a skill, with the reports that describe it. |
| [Hiding methods](hiding.md) | Ways to hide a technique inside a skill. Each row names the reports that show the method. |
